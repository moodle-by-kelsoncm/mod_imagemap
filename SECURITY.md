# Security Policy / Política de Segurança

## Supported versions / Versões suportadas

| Version | Supported |
| ------- | --------- |
| 1.3.x   | Yes       |
| < 1.3   | No        |

## Reporting a vulnerability / Reportando uma vulnerabilidade

Do not open a public issue. Use GitHub's *Report a vulnerability* (Security > Advisories) on this repository.
Não abra uma issue pública. Use o *Report a vulnerability* do GitHub (Security > Advisories) neste repositório.
