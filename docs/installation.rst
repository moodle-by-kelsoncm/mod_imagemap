Instalação
==========

Requisitos de Sistema
---------------------

- **Moodle**: 4.1 ou superior (versão mínima exigida `2023041000`)
- **PHP**: 8.0, 8.1 ou superior

Passo a Passo de Instalação
---------------------------

1. Acesse a pasta de módulos de atividade da sua instalação Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/mod

2. Clone o repositório nomeando a pasta como `imagemap`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/mod_imagemap.git imagemap

3. Acesse a página **Administração do site > Notificações** no Moodle para aplicar as atualizações de banco de dados.
