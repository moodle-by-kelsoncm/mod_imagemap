Instalação
==========

Requisitos
----------

* Moodle 4.5 LTS ou 5.3 LTS.
* PHP suportado pela sua versão do Moodle.

A partir de um ZIP
------------------

1. Baixe ``mod_imagemap-<versão>.zip`` das `releases <https://github.com/moodle-by-kelsoncm/mod_imagemap/releases>`_ ou do Moodle Marketplace.
2. Acesse *Administração do site > Plugins > Instalar plugins*, envie o ZIP e siga os passos.
3. Conclua a atualização em *Administração do site > Notificações*.

A partir do código-fonte
------------------------

Copie o repositório para ``mod/imagemap`` (``public/mod/imagemap`` no Moodle 5.1 ou superior) e acesse *Administração do site > Notificações*:

.. code-block:: bash

   git clone https://github.com/moodle-by-kelsoncm/mod_imagemap.git public/mod/imagemap

Idiomas
-------

O pacote traz só as strings em inglês. Os demais idiomas, inclusive o português do Brasil, vêm da ferramenta de tradução do Moodle (AMOS), pelos pacotes de idioma.
