# Visão Geral — moodle-mod_imagemap

O **`moodle-mod_imagemap`** é um módulo de atividade Moodle para criação de **mapas de imagens interativos** com áreas clicáveis e suporte a regras de exibição condicional baseadas no acompanhamento de conclusão.
