Guia do Administrador
=====================

Gerenciamento e Manutenção
--------------------------

- **Verificação de Integridade**: Certifique-se de que as tabelas `mdl_imagemap` e correlatas estejam íntegras no SGBD.
- **Logs de Eventos**: Todas as interações de criação, edição e exclusão de áreas geram eventos na API de Eventos do Moodle.
