Installation
============

System Requirements
-------------------

- **Moodle**: 4.1 or higher (minimum required version `2023041000`)
- **PHP**: 8.0, 8.1 or higher

Installation Steps
------------------

1. Navigate to the activity modules directory of your Moodle installation:

   .. code-block:: bash

      cd /path/to/moodle/mod

2. Clone the repository naming the folder `imagemap`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/mod_imagemap.git imagemap

3. Access the **Site administration > Notifications** page in Moodle to apply the database upgrades.
