Overview - moodle-mod_imagemap
=================================

**moodle-mod_imagemap** is an interactive activity for Moodle that allows creating clickable image maps with areas linked to modules, URLs, or custom actions, featuring support for activity completion conditions.

Key Features
------------

- **Integrated Graphic Editor**: Vector drawing tools to define rectangular, polygonal, and circular regions on the image.
- **Moodle Module Linking**: Direct integration with course activities, launching them and tracking completion.
- **Backup and Restore Support**: Full native support for Moodle's course backup and restore lifecycle.
- **Customizable CSS Styles**: Visual highlighting, borders, and animations for active areas.
