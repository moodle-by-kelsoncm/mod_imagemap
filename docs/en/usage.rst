User Guide
==========

Creating an Image Map
---------------------

1. In the desired course, turn **Edit mode** on.
2. Click **Add an activity or resource** and select **Image Map**.
3. Set the name and upload the main image to serve as the map.
4. Click **Save and display**.

Drawing Clickable Areas
-----------------------

1. On the activity view, select the option to edit areas.
2. Use the drawing tools (rectangles, circles, or polygons) to demarcate interactive regions.
3. Right-click the shape or access properties to configure:
   - Link type (external URL or Moodle course activity).
   - Visibility or completion condition.
4. Save changes.
